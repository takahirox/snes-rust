Help / Controls

Controls

Arrows: move · Z: B · X: A · A: Y · S: X · Q/W: L/R · Enter: Start · Shift: Select

Standard gamepads and multi-touch controls are supported. Slide across the D-pad for diagonals. Play activates audio; if sound is blocked, toggle Sound to try again.

Open a lawfully obtained local ROM. Personal ROMs and SRAM saves stay in this browser and are never uploaded.

Battery saves persist in local storage. Reset preserves SRAM and clears volatile memory. Loading a different cartridge restores its own save. Clearing browser storage erases saves.

If saving fails, keep this tab open to retain the save. Cartridge changes are blocked until saving succeeds. If restoration fails, use Retry restoring save after restoring storage access or repairing the saved data. Playback and cartridge changes remain blocked to protect existing saves.
